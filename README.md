# WebCam Controller

Windows PC의 웹캠과 마이크를 제어하고, 카메라 사용 여부를 실시간으로 감시하여 **텔레그램 알림**을 보내는 보안 유틸리티입니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 📷 카메라 제어 | 연결된 카메라 목록 표시, 클릭 한 번으로 활성화/비활성화 |
| 🎤 마이크 제어 | 연결된 마이크 목록 표시, 클릭 한 번으로 음소거/해제 |
| 👁️ 웹캠 감시 | 3초 간격으로 카메라 상태 자동 감시 |
| 📱 텔레그램 알림 | 이상 감지 시 스마트폰으로 즉시 알림 (4가지 이벤트) |
| 🖥️ 시스템 트레이 | 백그라운드 상주, 트레이 아이콘으로 조용히 동작 |
| 🔒 보안 저장 | Bot Token · Chat ID를 Windows DPAPI로 암호화 저장 |
| 🛡️ 파일 변조 감지 | 실행 시마다 SHA-256 해시 검증 → 변조 시 즉시 알림 |
| ⚙️ 시작 프로그램 | Windows 로그인 시 관리자 권한으로 자동 실행 |

## 텔레그램 봇 준비

### 1. Bot Token 발급
1. 텔레그램에서 `@BotFather` 검색 → 채팅 시작
2. `/newbot` 입력 → 봇 이름 설정
3. 발급된 **Bot Token** 복사 (예: `123456789:AABBcc...`)

### 2. Chat ID 확인
1. 텔레그램에서 `@userinfobot` 검색 → `/start` 입력
2. 표시된 **Your ID** 숫자 복사

### 3. 앱에서 설정
1. **알림 설정** 버튼 클릭 → **텔레그램** 탭
2. Bot Token · Chat ID 입력
3. **테스트 전송**으로 알림 확인
4. **확인** 버튼으로 저장

---

## 사용 방법

1. 텔레그램 설정 완료 후 **감시 시작** 버튼 클릭
2. 버튼이 빨간색 **"감시 중지"** 로 바뀌면 감시 시작
3. 창을 닫으면 트레이로 숨어서 계속 동작
4. 트레이 아이콘 더블클릭 → 창 복원 / 우클릭 → 메뉴

## 보안 기능

### DPAPI 암호화
Bot Token · Chat ID는 Windows DPAPI(현재 사용자 범위)로 암호화하여 저장합니다.
동일 PC · 동일 계정 외에는 복호화가 불가능합니다.

### 파일 무결성 검증
실행할 때마다 exe 파일의 SHA-256 해시를 HKLM 레지스트리 저장값과 비교합니다.
불일치(변조) 감지 시 텔레그램 알림 전송 후 프로그램을 종료합니다.

## 기술 스택

| 항목 | 내용 |
|------|------|
| 언어 | C# (.NET 8, WinForms) |
| 카메라 제어 | Windows SetupAPI (P/Invoke) |
| 마이크 제어 | Windows CoreAudio API (P/Invoke) |
| 카메라 사용 감지 | Windows Registry (CapabilityAccessManager) |
| 텔레그램 알림 | Telegram Bot API (HttpClient) |
| 설정 암호화 | Windows DPAPI (ProtectedData) |
| 파일 무결성 검증 | SHA-256 + DPAPI (HKLM 레지스트리) |
| 시작 프로그램 등록 | Windows Task Scheduler (schtasks) |
| 인스톨러 | Inno Setup 7 |
